# Inventory-and-Stock-Management-System
📦 STOCKR — Inventory & Stock Management System

A full-stack web application developed as a group project for managing
inventory operations in a business environment. Built with Java Spring Boot
on the backend and JSP Servlets on the frontend, styled with Bootstrap 5.

🔧 Tech Stack: Java • Spring Boot • JSP Servlets • MySQL • Bootstrap 5
📌 Features: User Management • Product Management • Stock Level Tracking
             Supplier Management • Order Management • Category & Reports
🎓 Academic project — SLIIT, Year 1, IT undergraduate program
